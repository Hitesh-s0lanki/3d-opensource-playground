# transformers MUST stay on 4.x.
# TripoSR's image tokenizer is a DINOv2 ViT and its checkpoint was saved with
# the 4.x parameter names (encoder.layer.N.attention.attention.query). The v5
# modeling refactor renamed these to layers.N.attention.q_proj, so loading the
# checkpoint under v5 fails with several hundred missing/unexpected keys.
# Upstream pins ==4.35.0; the 4.x ceiling is the actual constraint.
